# ClassPilot

Thoughtful, practical tools for teachers and schools.

ClassPilot is being built as a responsive teacher toolkit. The first milestone focuses on a fast, accessible foundation and a usable lesson planner.

## Current status

- Responsive public landing page
- Free lesson plan builder with editable inputs
- Generated lesson outline with print / Save as PDF
- No sign-in or server upload required for the first tool
- Initial SEO metadata and mobile layouts

## Stack

- Next.js App Router
- React
- TypeScript
- Plain CSS for a lightweight, custom visual system

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Product principles

- Teacher-first, mobile-friendly workflows
- Useful free tools before account complexity
- Keep student personal data out of AI prompts
- Make exports and printed resources practical
- Add features incrementally and verify each milestone

## Roadmap

1. Lesson planner foundation
2. Certificate maker
3. Worksheet builder
4. Quiz generator
5. Saved projects, school branding and optional paid plans
